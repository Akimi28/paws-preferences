# 🐾 Paws & Preferences

A fun and interactive web application that lets users discover their favorite cats or kittens! Users can swipe through cat pictures, like or dislike them, and see a summary of the cats they liked. Inspired by popular dating apps, but for cats! 😻

---

## **Live Demo**

Try it now on GitHub Pages:

## **Features**

- **Swipe Interaction:** Swipe right to like, left to dislike.  
- **Button Controls:** Like ❤️ or Dislike ❌ using on-screen buttons.  
- **Keyboard Support:** Arrow keys work for like/dislike.  
- **Dark Mode Toggle:** Switch between light and dark themes.  
- **Animated Feedback:** Smooth animations for like/dislike actions.  
- **Progress Indicator:** Shows how many cats are left.  
- **Hint for First Card:** First card shows how to interact.  
- **Result Summary:** Displays how many cats were liked and their thumbnails.  
- **Responsive Design:** Works on desktop and mobile browsers.  

---

## **How It Works**

1. The app loads a fixed number of random cat images from [Cataas](https://cataas.com/).  
2. Users interact with the cards by:
   - Swiping (drag with mouse or touch)
   - Clicking the **like** or **dislike** buttons
   - Using keyboard arrows (→ for like, ← for dislike)  
3. Each action is animated with **LIKE / NOPE** labels and heart or cross bursts.  
4. Once all cats are swiped, a **summary screen** shows:
   - Total cats liked  
   - Thumbnail images of the liked cats  
5. Users can click **“Try Again”** to restart.
